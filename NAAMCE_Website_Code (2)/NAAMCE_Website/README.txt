NAAMCE — Three-page student website

OPEN THE WEBSITE
1. Extract the entire ZIP folder.
2. Double-click index.html to open it in a browser.
3. Edit the HTML files using VS Code or a plain-text editor.
Keep assets beside the HTML files so the illustration loads. No installation needed.

RUN WITH NPM
From the repository root, run:
1. npm install
2. npm run dev
3. Open http://localhost:3000
Node.js is required. The site has no external package dependencies; npm run dev
starts a small local server for the files in this folder. In PowerShell, if
script execution policy blocks npm, use npm.cmd install and npm.cmd run dev.

FILES
index.html — Home
page2.html — Products & Services
page3.html — About & Contact

FICTIONAL CONTENT
NAAMCE is a real organization. This assignment concept does not claim to be its official website. Services, prices, promotions, origin story, team job titles, hours, and contact details are fictional. No real bookings or payments. The form validates required fields locally, shows a demo message, and does not send or store information.

RUBRIC MAP
Home: brand/tagline/hero image, three-sentence pitch, three highlights, CTAs to pages 2 and 3, mission statement.
Services: three offerings with descriptions/prices, three-step process, featured workshop and promo.
About: fictional origin story, three team bios/titles, mock contacts and demo form, hours and FAQs.
Styling: body, headings, paragraphs, header, main, images, and other elements styled using embedded style tags on every page.
